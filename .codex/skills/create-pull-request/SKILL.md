# Создание pull request

## Подготовка

- Определить текущую ветку, target branch, remote и коммиты, которые войдут в PR. Не предполагать target branch, если он не очевиден из repository workflow или явно не указан пользователем.
- Проверить рабочее дерево и сообщить о незакоммиченных изменениях: они не войдут в PR.
- Сверить описание с реальным diff и историей коммитов. Не заявлять о поведении, проверках или решениях, которых нет в ветке.
- Выполнить применимые проверки либо указать их фактический статус. Если проверки не запускались или завершились ошибкой, явно отразить это в PR.
- Если ветка ещё не опубликована, использовать правила skill `push-safely`; push выполнять только при явном разрешении пользователя.

## Заголовок и описание

- Писать заголовок и описание на русском языке.
- Если изменения относятся к Jira-задаче, начинать заголовок с её ключа: `KAN-5: ...`.
- Заголовок должен кратко отражать пользовательский или технический результат, без общих фраз вроде «разные изменения» или «обновления».
- Описание должно быть кратким, но достаточно подробным для ревью. Использовать только нужные разделы:

```markdown
## Что сделано

- <наблюдаемое изменение или принятое техническое решение>

## Проверки

- `<команда>` — <результат>

## Примечания

- <только если нужен контекст, ограничение или следующий шаг>
```

- В «Что сделано» группировать изменения по результату, а не перечислять все файлы и мелкие реализации.
- Не добавлять пустые разделы, шаблонные фразы, TODO без контекста или дублирование заголовка.
- Указывать связанный Jira-ключ или ссылку, если он известен.

## Создание и отчёт

- Создавать PR только по прямому запросу пользователя после проверки title, description, source branch и target branch.
- Не назначать reviewers, assignees, labels, milestone и не переводить PR из draft в ready без отдельного указания.
- После создания сообщить URL PR, source/target ветки и кратко перечислить включённые коммиты.
- При ошибке остановиться, привести безопасный контекст ошибки и не повторять создание PR автоматически.

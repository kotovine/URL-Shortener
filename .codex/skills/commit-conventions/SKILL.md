# Соглашения о коммитах

## Сообщение коммита

- Если работа связана с Jira-задачей, начинать subject с ключа и двоеточия: `KAN-5: ...`.
- Писать subject на русском языке.
- Формулировать subject существительным или именной группой, не глаголом в инфинитиве. Например: `KAN-5: Инициализация monorepo`.
- Делать subject коротким и описывающим основной результат одного коммита.
- Добавлять тело коммита только когда оно помогает понять существенные изменения, ограничения или причины решения; писать его на русском языке.

## Состав коммита

- Один коммит должен содержать одно законченное тематическое изменение.
- Не включать в коммит несвязанные пользовательские изменения или локальные файлы.
- Перед staging проверять `git status` и diff; перед коммитом проверять staged diff.
- Соблюдать правила из `AGENTS.md` для секретов, generated-файлов и naming с Jira.
